# Python Optimization Practice

This repository contains introductory exercises in mathematical optimization using Python and PuLP.

## Topics

- Linear Programming (LP)
- Mixed-Integer Linear Programming (MILP)
- Binary decision variables
- Knapsack and assignment problems
- Employee scheduling
- Transportation and facility location
- Shortest path optimization
- Supply chain optimization

## Mini Project: Supply Chain Optimization

A simplified production and transportation optimization model with two factories, two products, and two customer regions.

The objective is to minimize total operating, production, and transportation costs while satisfying customer demand and resource constraints.

## Current Status

Learning project. The examples are being reviewed, tested, and extended as part of my study of mathematical optimization.

## Tools

Python, PuLP, CBC Solver
